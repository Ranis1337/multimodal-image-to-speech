# Мультимодальный AI-ассистент: «Глаза + Редактор + Голос»
Проектный практикум по интеграции легковесных моделей с платформы Hugging Face в единый сквозной конвейер (Pipeline) для Google Colab.
---
## Описание проекта
Приложение принимает изображение, генерирует смысловое текстовое описание на английском языке, переводит его на русский язык и синтезирует естественную русскую речь.

**Сфера применения:** цифровой аудиогид, ассистивные технологии для людей с нарушениями зрения, автоматическая аудиодескрипция медиаконтента.
---
## Архитектура и используемые модели
Каскад состоит из трёх моделей, оптимизированных для работы на бесплатном GPU T4 (~1.4 ГБ суммарного веса):
| Этап | Модель на Hugging Face | Архитектура / Задача | Роль в конвейере |
| :--- | :--- | :--- | :--- |
| **1. Vision-to-Text** | `Salesforce/blip-image-captioning-base` | Vision Transformer + Text Decoder | Генерация текстового описания изображения (EN) |
| **2. Перевод** | `Helsinki-NLP/opus-mt-en-ru` | MarianMT (Seq2Seq) | Перевод сгенерированного описания (EN → RU) |
| **3. Text-to-Speech** | `facebook/mms-tts-rus` | VITS (Normalizing Flows) | Синтез русской речи из текста |в

## Быстрый запуск
### Запуск в Google Colab
1. Откройте блокнот проекта в репозитории и нажмите кнопку **Open in Colab**.
2. Включите аппаратное ускорение: **Среда выполнения** → **Сменить среду выполнения** → **T4 GPU**.
3. Последовательно выполните ячейки блокнота.
4. Откройте сгенерированную публичную ссылку `*.gradio.live` для взаимодействия через веб-интерфейс.
